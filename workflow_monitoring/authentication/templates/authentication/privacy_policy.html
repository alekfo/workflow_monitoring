🔒 Политика конфиденциальности

Последнее обновление: {{ last_updated|default:"07.04.2026" }}

Настоящая Политика конфиденциальности описывает, какие персональные данные собирает сервис Fieldlog (далее — Сервис), как они используются и защищаются. Используя Сервис (просмотр, чтение текста, отправка или загрузка информации) и предоставляя свои персональные данные, Пользователь даёт согласие на обработку персональных данных в соответствии с данной Политикой, если дополнительные требования к согласию не установлены настоящей Политикой.

1. Оператор персональных данных

Для целей настоящей Политики под «Оператором» понимается физическое лицо — Шленсков Алексей Александрович.

2. Состав обрабатываемых персональных данных

Оператор производит обработку следующих персональных данных:

  • Имя, фамилия, отчество (при наличии);
  • Адрес электронной почты;
  • Имя пользователя (логин);
  • Сведения о трудовой деятельности в рамках системы (задачи, объекты, оборудование).

3. Цели обработки персональных данных

  • Идентификация и аутентификация пользователя в системе;
  • Обеспечение работы функций мониторинга рабочих процессов;
  • Направление уведомлений, связанных с использованием системы;
  • Выполнение требований законодательства Российской Федерации.

4. Правовое основание

Обработка персональных данных осуществляется на основании Федерального закона № 152-ФЗ «О персональных данных» с согласия субъекта персональных данных.

5. Регистрация

Для получения доступа к материалам Сервиса Пользователю необходимо зарегистрироваться путём заполнения регистрационной формы, содержащей следующие персональные данные: фамилия, имя, отчество (при наличии), e-mail, имя пользователя (логин).

Пройдя процедуру регистрации, Пользователь считается принявшим условия Политики в полном объёме, без каких-либо исключений, оговорок, возражений.

При регистрации в Сервисе Пользователь обязан предоставить Оператору необходимую, достоверную и актуальную информацию для формирования профиля, включая уникальные для каждого Пользователя логин и пароль доступа к Сервису.

По завершении процесса регистрации Оператор становится обладателем учётных данных Пользователя. Оператор несёт ответственность за безопасность учётных данных, а также за все действия, совершённые на Сервисе под учётными данными Пользователя. Пользователь обязан немедленно уведомить Оператора о любом случае несанкционированного доступа к Сервису и (или) о любом нарушении безопасности его учётной информации.

6. Хранение и защита данных

Персональные данные хранятся на защищённых серверах и не передаются третьим лицам без согласия Пользователя, за исключением случаев, предусмотренных законодательством. Срок хранения — в течение срока действия учётной записи и 30 дней после её удаления.

7. Права субъекта персональных данных

Вы вправе:

  • получать сведения об обработке своих персональных данных;
  • требовать уточнения, блокирования или уничтожения данных;
  • отозвать согласие на обработку персональных данных.

Для реализации своих прав обращайтесь по адресу: alekfo1@yandex.ru.

8. Права и обязанности Оператора

Оператор вправе:

  • не удалять данные Пользователя, необходимые для хранения в соответствии с действующим законодательством Российской Федерации.

Оператор обязан:

  • использовать полученную персональную информацию Пользователя только в целях, названных в настоящей Политике;
  • принимать меры предосторожности для защиты конфиденциальности персональных данных Пользователя.

9. Изменения политики

Оператор оставляет за собой право изменять настоящую Политику. Актуальная версия всегда доступна в разделе Настройки.
