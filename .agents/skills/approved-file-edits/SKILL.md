# Только одобренные изменения

Правило пользователя распространяется на весь репозиторий, включая документацию, настройки, AGENTS.md и .agents.

1. Прочитай текущую версию файла и подготовь изменение без записи в проект.
2. Покажи пользователю полный unified diff конкретного файла. Для нового файла покажи всё содержимое как добавление, для удаления — всё удаляемое содержимое.
3. Кратко объясни цель и запроси отдельное явное подтверждение в терминале для этой операции.
4. Запиши файл только после подтверждения и только в одобренном виде.
5. Если исходный файл или предлагаемый diff изменился, запроси новое подтверждение.

Не объединяй несколько файлов в одно подтверждение. Поручение выполнить задачу, прежнее согласие, молчание и заранее разрешённая команда не заменяют одобрение конкретного diff.
Используй механизм интерактивного подтверждения инструмента; не обходи его другим способом записи. Не объявляй правило технически гарантированным одной лишь инструкцией.
Если терминальное подтверждение недоступно, оставь diff предложением и дождись пользователя, не применяй его.
Не создавай вспомогательные файлы в репозитории до согласования. Для подготовки предпочтительна память; временные файлы вне проекта допустимы только при разрешении пользователя.
Чтение и анализ не требуют согласования. До запуска генераторов, форматирования, миграций и проверок оцени побочные записи; записи в проект также должны быть согласованы.
После записи проверь, что результат совпадает с одобренным diff, и сообщи, какие файлы изменены.
